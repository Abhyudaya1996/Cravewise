# Learning Operating System

## Purpose

This repo should make learning visible. Every milestone should leave behind evidence of product judgment, technical fluency, and better prompts/evals.

## After Every Task

Update `learning-log/LEARNING_LOG.md` with date, milestone, what changed, what was learned, one product tradeoff, one technical tradeoff, and next action.

## Weekly Review

Review shipped evidence, unresolved blockers, prompts that worked well, eval failures, case study notes, and what to cut from scope.

## Learning Artifacts

- PRDs show product reasoning.
- Architecture docs show technical fluency.
- Eval files show AI quality thinking.
- Case studies show judgment and tradeoffs.
- Memory files show execution discipline.

## Anti-Pattern

Do not use the repo as a dumping ground for notes. Every note should either improve the product, help the next LLM session, or strengthen the case study.
