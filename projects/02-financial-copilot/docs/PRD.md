# PRD: AI Financial Copilot

## Summary

A trust-aware fintech assistant that explains financial offers, compares tradeoffs, and helps users make safer decisions.

## Problem Statement

Users struggle to understand credit cards, loan offers, fees, eligibility, repayment tradeoffs, and hidden costs. Fintech marketplaces often optimize for conversion rather than comprehension and decision quality.

## Primary User

Digitally active users comparing credit card or loan offers who need simple explanations, tradeoff analysis, and safer next-step guidance.

## Core Job To Be Done

When I receive a financial offer, I want to understand the real cost, risks, benefits, and alternatives, so I can decide confidently without missing hidden tradeoffs.

## Product Hypothesis

If we build a structured AI-assisted workflow around this decision, then users will make faster, more confident, and higher-quality decisions because the product combines context, structured reasoning, guardrails, and feedback loops.

## Out Of Scope

- regulated financial advice
- loan approval guarantees
- live bank integrations
- credit bureau pulls
- payments
- investment advice

## Success Metrics

- offer comprehension score
- time to understand offer
- risk flag accuracy
- comparison completion rate
- trust rating
- unsafe claim rate

## MVP Done Criteria

- Static user flow complete.
- Core AI workflow returns structured output.
- Output is validated before rendering.
- At least 5 eval cases exist.
- Case study notes explain product tradeoffs.
- Demo can be run locally.
