# CraveWise — Project Brief

## One-Line Pitch

An agentic food decision engine that helps users order food they are less likely to regret.

## Problem

Urban professionals face decision fatigue when ordering food. Food apps optimize for conversion and sponsored listings, but users care about craving, budget, health intent, mood, time, and post-meal satisfaction.

## Target User

Busy urban professionals aged 22-35 who order food multiple times per week and often regret impulsive choices.

## JTBD

When I am hungry and mentally tired, I want help choosing food that matches my craving, budget, health intent, and past satisfaction, so I can decide quickly without regretting the order later.

## MVP Scope

- food preference onboarding
- current context input
- 3 recommendation cards
- regret risk explanation
- meal feedback
- basic insights

## Out Of Scope

- live Zomato/Swiggy integration
- payments
- delivery tracking
- precise nutrition claims
- medical advice

## Agentic Angle

- Context Interpreter
- Preference Profiler
- Recommendation Agent
- Regret Prediction Agent
- Feedback Learning Agent
- Insights Agent

## Success Metrics

- time to decision
- recommendation acceptance rate
- satisfaction rating
- regret rating
- feedback completion rate
- repeat usage
