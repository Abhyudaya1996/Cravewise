# PRD: AI PM Simulator

## Summary

A multi-agent PM practice environment where users handle realistic product scenarios and receive structured feedback.

## Problem Statement

Aspiring and early PMs learn frameworks but rarely practice messy product judgment involving stakeholders, ambiguity, constraints, tradeoffs, and consequences.

## Primary User

Aspiring PMs, early PMs, and AI-native PM learners who want practical simulation-based product judgment training.

## Core Job To Be Done

When I am preparing for PM roles or trying to improve judgment, I want realistic scenarios with stakeholder tension and feedback, so I can practice decisions before facing them at work.

## Product Hypothesis

If we build a structured AI-assisted workflow around this decision, then users will make faster, more confident, and higher-quality decisions because the product combines context, structured reasoning, guardrails, and feedback loops.

## Out Of Scope

- guaranteed interview success
- generic chatbot coaching
- unbounded open chat
- too many scenarios in MVP

## Success Metrics

- scenario completion rate
- feedback usefulness
- decision quality score
- repeat practice rate
- rubric consistency
- agent relevance score

## MVP Done Criteria

- Static user flow complete.
- Core AI workflow returns structured output.
- Output is validated before rendering.
- At least 5 eval cases exist.
- Case study notes explain product tradeoffs.
- Demo can be run locally.
